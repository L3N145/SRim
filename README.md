# SRim

SRim is a quiet, autonomous abstract-life web app. The creatures have no explicit emotional or social-state model; their physical motion and interactions are intentionally open to interpretation.

## Current interaction

- Tap the world to create an expanding ripple.
- The ripple physically perturbs nearby creatures.
- Ordinary locomotion continues independently of tap reactions and larger behavior events.
- Bodies have layered breathing, contraction, contour fluctuation, and individual activity differences.
- Rare morphology changes persist for a while before slowly recovering.
- A rare birth event creates a genuinely new creature with inherited and slightly varied traits.
- Online image fragments can appear inside a creature as if seen through translucent tissue.
- Microphone input is optional.

## Design principle

Physical animacy is intentionally designed. Social or intentional meaning is not explicitly encoded; it should emerge as an interpretation of observable events.
